# 주간 계획 재정립 · 2026-11-05

근무·건강·우선순위 변화로 이번 주 계획의 전제가 달라졌을 때 남은 약속을 다시 정한다. 일반 일정 이동과 구분하며 현재 진행 중인 주에만 적용한다. 사용자 데이터의 실제 재정립이나 목표 선택은 이번 구현에 포함하지 않았다.

## 사용자 흐름

실행 화면의 `주간 계획 재정립` → 상황 변화와 짧은 사유 작성 → 남길 미완료 실행 선택 → 필요하면 기존 목표에 이번 주만의 새 약속 추가 → 변경 요약 확인 → 저장. 저장하지 않은 시간표·하루 템플릿이 있으면 먼저 저장하거나 취소한다. 모달 닫기·이탈은 작성 내용을 보호하고, 저장 중 닫기와 중복 제출을 막는다. 버전 충돌은 제안을 유지한 채 오류로 표시한다.

적용일은 서버의 현재 평가일로 고정한다. 하루는 한국 시간 04:00부터 다음 날 04:00까지다. 04시를 지나거나 다른 화면에서 주/주기 버전이 바뀌면 기존 확인 내용으로 저장할 수 없다. 미래 예약이나 과거 소급 재정립은 제공하지 않는다.

완료 실행과 닫힌 평가일의 미완료 실행은 변경 당시 이력으로 남는다. 오늘의 미완료·미래 날짜·날짜 미정 실행은 유지하거나 제외한다. 유지한 실행은 같은 ID·날짜·시간·독서 초안을 계속 사용하고, 저장 후 기존 일간/주간 일정 도구로 이동한다. 제외한 실행은 자동 이월하지 않는다. 새 약속은 기존 목표에 연결해 행동·이진 완료 기준·최소 횟수 또는 오늘부터 매일 1회를 정한다. 이 화면은 미래 주차의 목표나 전술을 수정하지 않는다.

## 점수와 기록

매 재정립 시 당시의 목표·전술·실행·완료 시각·독서 기록·평가·점수를 스냅샷으로 보존한다. 기존 감사 로그도 남긴다. 새 계획은 남겨둔 미완료 실행과 새 약속으로 계산한다. 이미 끝난 실행은 새 계획에서 다시 완료할 항목으로 만들지 않는다.

- 재정립 후 주간 점수: 남은 전술별 최소 약속 실행률에 동일한 비중. 초과 실행은 기존 방식으로 최대 100%.
- 변경 당시 원안/이전 계획 진행률: 스냅샷에 저장한 시점의 값. 주 마감 원안 달성률이나 새 점수와 합친 값이 아니다.
- 최소 약속 없이 선택 실행만 남긴 전술: 점수 비중 없음. 선택 실행의 미완료는 감점 없음.
- 남은 최소 약속 없음: 100%가 아닌 계획 없음(N/A).
- 주기 점수 추이: 재정립 후 점수에 `재정립` 표시와 변경 당시 원안 진행률을 함께 표시. 두 점수를 평균하지 않는다.

실행 화면의 재정립 이력에서 전후 사유·유지/제외/추가 횟수와 당시 전체 실행·독서·평가를 열어볼 수 있다. 재정립 전 평가일의 일간 기록과 점수는 읽기 전용이다. 적용 당일은 새 기준으로 표시하며, 당일 변경 전 완료는 이력에서 확인한다. 독서 노트 모음/Markdown에는 이력의 기록도 포함하고 같은 실행 ID의 최신 기록 한 개만 사용한다. 캘린더는 보존된 완료·지난 실행과 현재 약속을 포함하되 재정립으로 제외한 미래 블록을 다시 내보내지 않는다. 이미 외부 캘린더에 가져간 일정은 자동 삭제하지 않는다.

## 저장과 구현

- `POST /api/cycles/:cycleId/weeks/:week/replan`: 주/주기 버전, 현재 평가일, 이유, 메모, 유지할 ID, 새 약속, 명시적 확인을 검증한다. 기존 소유권 검사·행 잠금·트랜잭션을 재사용한다.
- `weeks.state.replans[]`: 재정립 메타데이터·변경 당시 스냅샷·점수. 기존 주는 이 필드 없이 동일하게 작동하므로 SQL migration은 없다.
- 현재 작업 목록은 `state.tactics/occurrences`, 지난 단계는 `replans[].snapshot`에 있다. 이력을 중첩 복제하지 않는다.
- 한 주 최대 실행 600회, 새 약속 20개, 재정립 이력 20회. 선택 실행은 최소 횟수로 승격하지 않는다.
- 재정립 이후 약속은 이전 평가일에 배치할 수 없다. 제외했던 원래 전술 ID의 재사용은 거부하며 새 약속으로 추가한다. 기존 전술 추가 기능으로 매일 전술을 새로 만들 때에도 오늘부터의 날짜만 생성한다.
- 일정 undo/redo는 재정립 저장 시 초기화한다. 주간 평가 초안과 근무·생활 시간표 초안은 유지한다.

핵심 파일: `shared/week-replanning.js`, `server/week-replanning.js`, `web/src/WeekReplanning.jsx`. 회귀 범위는 점수·읽기 기록·캘린더·전술 추가·일간/주간 일정 공유다. 검증 결과는 `docs/STATUS.md`를 따른다.
