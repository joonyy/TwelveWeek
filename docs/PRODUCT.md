## 3년 비전과 목표 연결 · 2026-10-08

- 목표 목록 옆에 3년 개인 생활·커리어 비전을 표시한다. 모바일에서는 목표 목록 위에 표시하며, 비전 화면으로 돌아가 수정할 수 있다.
- 각 목표의 **3년 비전 연결 선택**에서 관련 항목을 여러 개 선택·해제한다. 연결한 문구는 목표 목록과 다음 목표별 계획 화면에 함께 표시한다. 연결은 선택 사항이며 착수 조건이나 실행 점수에 포함하지 않는다.

- 기존 비전 문자열·목표/전술 ID를 유지하며 연결과 항목 ID를 계획 JSONB에 저장한다. 기존 자료는 화면을 열 때 호환 구조로 준비하고 다음 명시적 저장에서 반영한다. SQL migration은 필요하지 않다.
- 자유 서술은 줄바꿈으로 나눈 내용을 선택 단위로 삼는다. 일치하는 문단의 순서 변경과 한 문단의 문구 수정은 ID를 유지한다. 여러 문단을 동시에 다시 써 대응이 불명확해지면 새 ID를 부여하고 기존 연결을 검토 표시로 남긴다.

| 계획 없음 | 기본 약속이 없으면 0점·100점 대신 평가 없음이다. 선택 실행만 있는 날도 동일하며 추가 실행 결과를 별도 표시한다. 미배치 기본 실행은 주간 최소 기준에 포함하되 일간 분모에서는 날짜를 배치할 때까지 제외한다. |
| 실행 횟수 추가 | 일간·주간 배치와 시간표 복사에서 기존 전술에 선택 실행을 추가한다. 최소 약속 N회와 전술별 비중은 고정한다. 완료한 추가 실행은 그 전술의 주간 최소 약속 달성에 반영하고, 초과분은 별도로 표시하며 실행률은 100%에서 제한한다. 미완료 추가 실행은 일간·주간 점수를 낮추지 않는다. 일간 점수는 원래 날짜별 약속만 평가하고 추가 실행은 별도로 기록한다. 다른 전술의 미완료나 빠진 매일 전술을 대신하지 않는다. 선택한 주만 저장하며 미래 계획 재생성 후에도 추가 기록을 유지한다. 오늘 이후에 배치하고 전술당 총 50회·주당 600회 제한을 유지한다. |
| 주중 표시 | 진행 중에는 현재까지의 실행률이다. 기한 전 미완료는 최종 실패 판정과 구분한다. 합격선 85%는 두지 않는다. |
| 반복 형태 | 주 N회 이상, 매일 1회, 선택한 각 주 최소 1회. 선택한 여러 주에 once 전술을 배치하면 각 주에 최소 1회씩 약속한 것이다. 불규칙한 주별 최소 횟수는 미래 계획 변경으로 조정한다. 초과 실행은 별도 등록하며 최소 횟수를 자동으로 올리지 않는다. |
| 시간 배치 | 모범 주간의 빈칸을 마우스로 드래그하면 같은 요일 안에서 30분 단위로 길이를 선택한다. 기존 블록의 최대 길이 12시간을 유지한다. 클릭·키보드·추가 버튼은 정리본의 3시간 기본값으로 시작하며 수정 가능하다. 터치에서는 스크롤과 탭 입력을 유지한다. 하루 축은 04:00~다음 날 04:00, 처음에는 07:00 근처를 보여준다. 겹친 일정은 옆으로 나란히 표시하며 자동으로 이동시키지 않는다. |
| Apple Calendar | iCloud 기존 일정을 직접 불러와 비교하고, 검토 후 새 일정 생성 또는 기존 일정 연결. 기존 .ics 다운로드도 유지한다. 자동 양방향 동기화는 아니다. 실제 iCloud 계정 연결·반영은 별도 확인이 필요하다. |
| 13주차 | 12주 점수 추이, 선택형 회고 입력, 주기 마무리. 별도 실행 점수·자동 다음 목표 생성은 없다. |
| 안내와 AI | 8요소 안내는 고정 문구. 장기비전에 한정한 대화·수정·재개, 외부 AI용 MCP, 선택한 대화 가져오기와 로컬 Codex resume를 지원한다. 모델/API 키는 사용자가 연결한다. 개인별 전술 생성은 포함하지 않는다. [AI 연결 범위](AI_INTEGRATION.md) |
| 운영 구성 | 프론트 Render Static Site, API Render Web Service. 외부 keepalive 스크립트 및 선택형 GitHub Actions 준비. 실제 배포와 자동화 활성화는 미실행. |

## 데이터 모델과 보존

`profiles → cycles → weeks`로 소유 범위를 고정한다. 계획은 구조가 검증된 JSONB로 저장하고 주간 데이터에는 해당 주 목표·전술·완료 조건·지표 기준을 함께 보존한다. 목표나 지표 이름을 바꿔도 이전 주 기록은 바뀌지 않는다. 별도 sessions 테이블은 만료·폐기 가능한 임의 토큰의 해시를 저장한다.

계획/실행/일정/평가 저장은 DB transaction과 버전 번호를 사용한다. 동시에 열린 화면에서 이전 버전으로 덮어쓰면 409로 거부한다. 변경 감사 기록은 DB에 남기며 사용자용 기록 조회 UI는 현재 범위 밖이다. 어떤 오류도 저장 성공으로 표시하지 않는다.

계획이나 실제 경험은 사용자 데이터다. 예시를 사용자의 실제 목표·수치로 자동 등록하지 않는다. 테스트 데이터는 별도 `_test` DB에만 만든다.

## 이번 버전의 경계

이 제품은 안내를 읽고 자기 계획을 만들며 실행·결과를 평가하는 첫 사용자용 흐름이다. 사진에 적힌 모든 아이디어를 새 확정 요구로 취급하지 않는다. 주간 모임 강제, 책임감 점수, 모든 생활 TODO의 점수 편입, 수면·회복 강제 목표, VIGIL 자동 개입은 없다.

실제 10/5 시작과 한 주의 사용 경험은 테스트 통과와 별개다. 첫 실제 사용 후 안내의 길이, 날짜 이동 시 일간 점수 처리, 주별 횟수 조정 방식부터 검토한다.
