# 제품 규칙과 구현 판단

2026-10-06. 사용자 합의와 구현 중 선택한 기본값을 구분한다. 본 프로젝트는 사용자 개인 SecondBrain의 파일을 읽어야 시작할 수 있는 서비스가 아니다.

## 사용자 합의

- SecondBrain의 도구 선택은 Obsidian, 12주 제품은 독립 웹 서비스. VIGIL 통합은 선행 조건이 아니다.
- 장기 비전·3년 비전 → n개 12주 목표 → 목표별 12주 계획(전술/실행 주차), 장애물과 대응, 선행·후행지표. 모범 주간과 삶의 태도 9·10·11은 공통 영역이다.
- 책임·헌신·위대해지는 순간, 비전·계획·프로세스 관리·평가·시간 활용의 8요소를 사용하는 순간에 안내한다. 문구는 책 원문 인용이 아닌 사진·대화 기반 적용 안내다.
- 최초 계획은 2026-10-05~12-27의 12주였다. 2026-10-06 사용자가 개인 사정에 따른 11주 운영과 기간 축소를 요청했다. 시작일은 월요일이며 실행 기간 다음 1주를 회고·회복·다음 목표 준비에 사용한다. 실제 시작일은 사용자가 앱에서 선택한다.
- 전술은 주간 단위로 계획하고 실제 일정은 모범 주간을 참고해 배치한다. 날짜 지정은 가능하며 주차 지정을 기본으로 한다.
- 일간 10분, 주간 30분 평가. 일간 점수는 완료/계획 횟수. 각 실행은 완료 또는 미완료다.
- `주 3회 5km 달리기`는 전술 하나. 2회 실행이면 전술 전체는 미완료, 실행률은 2/3.
- 주간 점수는 전술별 실행률의 산술평균. 5개 중 한 전술 2/3, 나머지 완료면 93.333…%. 원래 분수로 계산하고 표시만 반올림한다.
- 이번 주 전술의 취소·축소는 기존 평가 기준을 줄이지 않는다. 이월은 없다. 다음 주 이후 계획은 조정 가능하다.
- 같은 주 일정 이동은 주간 전략을 유지하는 범위에서 가능. 매일 전술의 빠진 날을 다른 날로 대체하지 않는다.
- 평가일 D는 한국 시간 D 04:00~D+1 03:59:59.999. 실제 캘린더 시각과 별개다.
- 선행·후행지표는 함께 검토하며 결과 변화가 실행 점수를 바꾸지 않는다.
- Render + Aiven, 사용자별 데이터, 이름 선택으로 진입, 긴 로그인 유지. 전용 원격 자원은 아직 없으며 배포 설정을 준비한다.

## 입력 화면 후속 요청 반영 · 2026-09-30

- 장기 비전, 3년 개인 생활·커리어 비전은 **목록 입력 기본**, 자유 서술 선택 가능. Enter/항목 추가/삭제를 지원하고 전환해도 내용과 순서를 유지한다.
- 신규 계획에는 **목표 3개와 목표별 전술·장애물 입력칸**을 미리 준비한다. 목표 수를 3개로 제한하지 않는다. 완전히 비어 있는 칸은 착수와 점수에서 제외하며, 일부 내용을 쓴 목표는 착수 전에 필수 항목을 확인한다.
- 모범 주간은 월~일과 시간축이 있는 **주간 캘린더**다. 빈 시간대를 누른 채 위아래로 드래그하면 30분 단위로 선택 범위를 표시하고, 놓으면 시작 시각·길이가 채워진 활동 입력창을 연다. Esc 취소, 화면 끝 자동 스크롤, 블록 편집·삭제·드래그 이동을 지원한다. 실제 일정 화면도 같은 캘린더에서 모범 주간을 점선 배경으로 보여준다.
- 책임은 IMG_0076을 다시 읽고 네 가지 태도와 개인 생활·일에서 실천할 노력의 목록으로 복원했다. 예전 단일 책임 메모는 별도로 보존한다.
- 헌신은 IMG_0077의 **7영역 바퀴**로 구성한다. 배우자·연인과의 관계, 가족, 공동체, 건강, 사적인 영역, 비즈니스, 종교. 각 영역에서 목표 선언·핵심 활동·헌신 비용을 나란히 작성하고, 비용을 감수할 핵심 활동에 동그라미를 표시한다. 기본 3행이며 추가·삭제할 수 있다. 점수 그래프나 실행 목표 자동 생성 기능은 아니다.
- 기존 글·목표 ID·사용자 지정 헌신 영역을 보존한다. 기존 계획의 목표 개수는 임의로 3개로 바꾸지 않는다. 내용이 전혀 없는 기존 초안만 작성 화면에 기본 3칸을 제공한다.

## 데이터 모델과 보존

`profiles → cycles → weeks`로 소유 범위를 고정한다. 계획은 구조가 검증된 JSONB로 저장하고 주간 데이터에는 해당 주 목표·전술·완료 조건·지표 기준을 함께 보존한다. 목표나 지표 이름을 바꿔도 이전 주 기록은 바뀌지 않는다. 별도 sessions 테이블은 만료·폐기 가능한 임의 토큰의 해시를 저장한다.

계획/실행/일정/평가 저장은 DB transaction과 버전 번호를 사용한다. 동시에 열린 화면에서 이전 버전으로 덮어쓰면 409로 거부한다. 변경 감사 기록은 DB에 남기며 사용자용 기록 조회 UI는 현재 범위 밖이다. 어떤 오류도 저장 성공으로 표시하지 않는다.

계획이나 실제 경험은 사용자 데이터다. 예시를 사용자의 실제 목표·수치로 자동 등록하지 않는다. 테스트 데이터는 별도 `_test` DB에만 만든다.

## 이번 버전의 경계

이 제품은 안내를 읽고 자기 계획을 만들며 실행·결과를 평가하는 첫 사용자용 흐름이다. 사진에 적힌 모든 아이디어를 새 확정 요구로 취급하지 않는다. 주간 모임 강제, 책임감 점수, 모든 생활 TODO의 점수 편입, 수면·회복 강제 목표, VIGIL 자동 개입은 없다.

실제 10/5 시작과 한 주의 사용 경험은 테스트 통과와 별개다. 첫 실제 사용 후 안내의 길이, 날짜 이동 시 일간 점수 처리, 주별 횟수 조정 방식부터 검토한다.
