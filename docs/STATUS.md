## 입력 화면 개선 · 사용자 후속 요청 반영

- 플로팅 저장: 계획 작성의 모든 탭에서 오른쪽 아래 원형 저장 아이콘을 고정 표시한다. 기존 저장 함수를 재사용하며 미저장 변경, 저장 중, 저장 완료 상태를 표시하고 중복 클릭을 막는다. 보관된 주기에는 표시하지 않으며 모바일 안전 영역·하단 메뉴·저장 알림과의 간격을 확보했다.
- 장기 비전과 3년 비전: 목록/자유 서술 선택, 목록 기본, 항목 추가·삭제·Enter 입력. 내용·입력 방식 저장 및 복원.
- 새 계획: 목표 3개와 목표별 전술·장애물 칸을 준비. 빈 기본 목표는 착수·주간 분모에서 제외하며 일부 작성한 목표의 필수 항목은 검사.
- 목표 먼저 나열하기: 목표 목록과 목표별 계획을 별도 화면으로 분리. 목록에서 제목 전체를 먼저 보고, 다음 화면에서 목표를 선택해 성공 기준·기대 변화·전술·장애물·지표를 작성한다. 목록 수정·목표 전환·저장·새로고침 후 목표/전술 ID와 기존 내용 유지, 이름이 없는 기존 계획 접근, 모바일 가로 넘침 없음을 확인했다.
- 3년 비전 연결: 목표 목록 옆에 개인 생활·커리어 비전을 보여주고, 목표마다 관련 항목을 복수 선택·해제한다. 다음 계획 화면에도 연결 문구를 표시한다. 비전 항목 ID와 연결을 DB에 저장하며 문구 수정·목록 삽입·삭제·자유 서술 순서 변경에도 연결을 보존한다. 삭제되거나 대응이 불명확해진 항목은 `연결 검토`로 남긴다. 기존 목표·전술·주간 점수 기준은 유지한다.
- 정리노트 기반 작성 안내: 사진 11장과 템플릿 초안을 재대조해 1~11 영역마다 질문·작성 포인트·유의할 점을 기본으로 펼쳐 표시한다. 장기 비전의 상상과 나열, 목표의 다섯 조건, 전술의 우선순위·완료 조건·실행 주차, 장애물과 대응, 행동/결과 지표, 시간 블록과 삶의 태도를 구체적으로 안내한다. 각 입력란의 설명과 캘린더 블록별 역할도 함께 표시한다. 일간·주간·주기 회고는 정리노트와 사용자 추가 운영 규칙을 구분해 안내한다.
- 모범 주간: 실제 주간 캘린더 UI, 빈 시간대 클릭 또는 위아래 드래그 생성. 드래그 중 30분 단위 시간 범위 미리보기, 놓으면 해당 길이로 입력창 열기, Esc 취소와 화면 끝 자동 스크롤. 시간 블록 수정·삭제·30분 단위 드래그 이동. 04:00를 넘기는 블록과 겹친 블록 표시. 실제 일정도 같은 캘린더로 표현.
- 책임: IMG_0076의 네 가지 태도 및 개인 생활·일에서 실천할 목록. 기존 책임 메모 유지.

## 실행 및 배포 재개

2026-10-21 일정 조작과 일간 작업 화면을 확장했다. 단위 39개·Chromium 전체 19개·프론트 빌드·`git diff --check`를 통과했다. 미배치 실행 드롭과 이동, 시작/종료 양쪽 조절·Esc 취소·저장 실패 시 기존 일정 보존, 매일 전술 날짜·완료 기록 보호, 새로고침 복원과 실행 횟수/점수 불변을 확인했다. 원형표의 일간 배치/수정은 같은 주간 저장 경로를 사용하고 미래 주 배치 해제만 허용한다. 원형 범위 드래그, 모범 주간 호버·포커스 상세, 한국 시간 갱신과 25/5 반복·10분 휴식·일시정지·새로고침 복원을 확인했다. 390px 화면의 가로 넘침과 Chromium 터치 입력의 가장자리 조절도 검증했다. 실제 iPhone 기기 검증은 포함하지 않는다.

사용자 확인으로 현재 실행 주기의 모범 주간에 일요일 평가일의 다음 날 01:00~01:30(실제 월요일 새벽) 주간 평가 고정 블록을 저장했다. 목표·전술·실행 횟수에는 추가하지 않았다. 타이머 저장은 이 브라우저의 주기별 localStorage이며 서버 실행 기록이나 다른 기기와 동기화하지 않는다.

2026-10-21 후속으로 원형표의 전술별·모범 주간 활동별 색상과 색상 안내, `이번 주 시간표 조정`을 추가했다. `plan.weeklyModelWeeks`의 선택형 JSON 저장 구조를 확장했으며 SQL migration은 필요하지 않다. 현재 주만 저장·기본 시간표 반영·별도 설정 해제와 저장 후 복원을 검증했다. 기본 반영 시 이미 시작한 다른 주와 별도 설정을 보존하고, 실제 실행 상태와 미저장 주간 평가 초안도 유지한다. 단위 41개·전체 API 29개·전체 Chromium 20개·프론트 빌드를 통과했다. 미저장 평가 보존을 추가한 뒤 해당 주차별 조정 흐름도 재검증했다. 실제 사용자의 근무 시각이나 목표를 시험용으로 변경하지 않았다.

같은 날 전술 선택과 `이번 주 계획표`를 추가했다. 신규 주차별 블록에서 전술·실행 회차를 선택해 실제 일정으로 저장하고, 이미 배치된 회차는 이동한다. 완료된 실행과 매일 전술의 날짜 조건을 유지하며 모범 주간 배경에 전술 블록을 중복 추가하지 않는다. 실제 실행을 포함한 시간표 편집과 별도의 목표별 주간 계획표에서 일정 변경을 공유한다. 계획표는 해당 주에 적용된 기준을 읽는다. 전체 Chromium 21개와 빌드를 통과했고, 편집 화면에서 계획표로 바로 전환하는 마지막 개선 뒤에도 해당 흐름을 재검증했다. 이번 변경은 UI이며 API·DB schema와 실행 횟수·점수 계산은 변경하지 않았다.

2026-10-21 처음에는 실행 화면 공통에 삶의 태도 전체 목록을 표시했다. 이후 사용자가 원한 것은 한 항목씩 무작위로 상기시키는 방식이라고 정정하여 아래의 작은 카드로 대체했다. `이번 주 계획표`에도 주차별 시간표와 실행 일정을 표시하고 같은 일정 편집을 공유한다. 주차별 설정 우선·미설정 시 모범 주간 사용 여부를 명시했다. Apple `.ics`에는 해당 주의 근무·생활 블록과 배치한 실행을 함께 넣는다. 04시를 넘는 수면 블록은 다음 평가일에도 표시하고, 월요일 아침은 전주에서 이어지는 블록을 사용한다. 인접 주 내보내기의 같은 블록은 UID를 유지한다.

단위 43개·전체 PostgreSQL/API 29개·전체 Chromium 22개·프론트 빌드를 통과했다. 작성된 삶의 태도 표시·선택 상태·접기·새로고침, 주차별/기본 시간표 선택과 실제 `.ics` 다운로드 내용, 야간 수면의 UTC 시각·주 경계·UID, 점수 불변과 모바일 가로 넘침을 확인했다. 실제 Apple Calendar 앱에서 파일 가져오기는 별도 확인 대상이다.

사용자 확인 후 실제 로컬 DB의 기본 모범 주간과 이번 주 별도 시간표에 매일 03시 취침을 저장했다(저장 당시 주기 버전 60). 실제 요일 기준 월·화·목·금은 09시, 수·토·일은 10시 기상이다. 기존 주말 밤잠 연장 블록은 새 수면 블록으로 대체했고 다른 근무·개인 작업은 유지했다. 목표·전술과 10개 주 전체의 실행 상태가 저장 전후 동일함을 확인했다. 실제 API의 주차별 `.ics`에서도 수면의 날짜·종료 시각과 첫 월요일로 이어지는 블록을 확인했다.

2026-10-21 삶의 태도 표시를 작은 무작위 카드로 수정했다. 책임 실천은 문장별, 지켜냈던 약속과 선택한 헌신은 약속별로 한 항목만 보여준다. 선택하지 않은 초안은 제외한다. 화면 작업 중 문구를 자동 교체하지 않으며, `다른 약속 보기`는 모든 후보를 한 번씩 뽑은 뒤 다시 섞는다. 행동·비용·얻었던 변화는 해당 카드에서 필요할 때 펼친다. 기존 전체 내용과 편집 화면, DB·실행 기록·점수는 변경하지 않았다. 브라우저 일정 흐름 7개와 프론트 빌드·`git diff --check`를 통과했다. 한 번에 한 항목만 표시, 전체 후보를 반복 없이 순회, 미선택 초안 제외, 화면 전환 중 문구 유지와 390px 가로 넘침 없음을 확인했다. 서버·API 변경이 없어 API 검증은 직전 전체 29개 통과 기록을 유지한다.

2026-10-21 실행 배치 창을 목표 선택 → 전술/회차 선택으로 변경했다. 기존의 미배치 회차만 나열하던 방식 때문에 주 3회 전술이 세 줄로 보이고 이미 배치된 실행·매일 전술·다른 주차 전술이 빠지던 이유를 구분한다. 목표를 선택하면 해당 목표에 집중하도록 선택 목록을 접고, 전술은 한 행씩 완료 기준과 미배치/배치/완료 상태를 보여준다. 배치된 회차 이동과 매일 전술의 해당 평가일 이동도 같은 저장 경로를 사용한다.

배치 창에서 새 전술을 추가하거나 이번 주에 없던 기존 전술을 가져올 수 있다. 사용자가 이번 주 평가에도 포함하기를 선택했으므로 기존 약속·완료·회고는 유지하고 새 전술의 계획 회차를 더한다. 첫 회차를 선택한 시간에 배치하며 이후 적용 주차는 직접 선택한다. 주간 점수의 분모·비중 변경과 매일 전술의 7일 평가를 안내한다. 새 API는 주기·주차 버전을 함께 확인하고 현재 주 추가와 이후 계획 변경을 한 트랜잭션으로 저장한다. 지난주·타인 소유·중복 추가를 거절하고 미래 주 용량 초과 등 중간 실패 시 전체를 되돌린다. 일반 계획 편집으로 현재 주의 기존 기준을 축소할 수 없는 규칙은 유지한다. 실제 사용자 목표·전술·실행 데이터는 검증용으로 변경하지 않았다.

단위 43개·전체 PostgreSQL/API 35개·프론트 빌드·`git diff --check`를 통과했다. Chromium 전체 실행에서 기존 22개가 통과했고, 목표 선택 후 목록을 접는 UI에 맞춰 신규 흐름의 안내 문구 확인을 수정한 뒤 해당 흐름도 재실행해 통과했다(총 23개 흐름). 신규 흐름은 목표별 표시·반복 전술 한 행·배치된 회차 이동·매일 전술 날짜 유지·기존 전술 가져오기·새 전술의 이번 주/이후 주 반영·중복 방지·409 실패 후 입력 유지·미저장 회고 보존·새로고침 복원·390px 가로 넘침 없음을 검증했다.
